## 実装・受入の残作業

| 領域 | 残作業と完了の証拠 |
|---|---|
| 登録・編集 | 名前、品種、田植え日、出穂日の編集導線がない。所有者限定更新と変更後再計算を実装し、他利用者拒否・再試行・日付修正を試験する |
| 進捗 | スナップショットの読み取りは追加済み。実積算値を持つ各状態で一覧の％・残り気温・欠測警告をブラウザ検証する |
| 状態の説明 | 出穂前、目安なし、気象未取得を混同しない。反映日がない場合の「未設定まで」を解消する |
| UI | カードの名前・状態・補足の強弱、PCの集計領域、空フィルター案内、色見本への導線を改善。スマホとPCの実画面で確認する |
| 並び順 | 現状は状態順のみ。同状態内の順序と「刈る順」の文言を一致させる |
| 透明性 | 適用目安は表示追加済み。代表観測地点・鮮度・欠測、日別推移と計画上のグラフを詳細から確認できるようにする |
| 年度・履歴 | 固定年度の箇所を確認し、翌年作付けと過去年の閲覧を通しで試験する |
| 気象 | 初回バックフィル、訂正再取得、再試行、排他、日次実行と更新遅延検知を現行本番状態で再確認。過去の成功記録だけで完了にしない |
| 認証 | メール登録・再設定・Googleログインの本番縦通し、アカウント分離を確認する |
| 公開 | 対象コミットのCI、デプロイ先と反映版、主要導線を確認する |
| 運用 | バックアップ・復元試験、監視、免責表示、依存監査と秘密情報検査の現行結果を残す |
| 実機 | iPhone/Android PWAのインストール、通信復帰、屋外の視認性、農家による操作確認が必要 |
