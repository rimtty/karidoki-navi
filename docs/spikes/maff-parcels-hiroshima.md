# 広島県筆ポリゴン取込スパイク

- 状態: 取込方式確定、実データ取込待ち
- 対象: 2026年データ・広島県・三原市久井町

## 公式データ

農林水産省は2026年の広島県筆ポリゴンをFlatGeobuf 6分割、合計342.6MBで公開している。データは世界測地系の緯度経度座標で、利用時は都道府県内の全分割ファイルを取得するよう案内されている。

## 取込方針

Supabase FreeのDB上限を考慮し、広島県全件を本番DBへ投入しない。

1. 6ファイルをローカルの一時領域へ取得する。
2. ファイルごとのSHA-256と取得日時を記録する。
3. `ogrinfo`で属性・座標系・件数・形状を検査する。
4. 三原市（自治体コード34204）で抽出し、さらに久井町周辺を対象にする。
5. 無効形状を検出し、修復件数を監査ログへ残す。
6. 抽出データだけをPostGISへ投入する。
7. MVT APIでは表示範囲・ズームレベルで絞り、必要属性だけを返す。

登録済み圃場は`fields.geom`へコピーするため、翌年度の候補データ入替で利用者の圃場形状を変更しない。

## リリース前確認

- FlatGeobufの自治体コード列名を公式データフォーマットと実ファイルで照合する。
- 久井町だけを属性で切り出せない場合は、三原市行政界との空間交差で抽出する。
- 配信するMVTに個人情報や不要な原典属性を含めない。
- 地図画面に筆ポリゴンの出典とデータ年を表示する。
