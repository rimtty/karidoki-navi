# 三原市初期品種・VarietyRule調査

- 状態: 品種マスター確定、積算温度ルール調査中
- 決定日: 2026-09-03
- 対象地域: 広島県三原市久井町

## 初期品種マスター

| 品種 | 採用根拠 | ルール状態 |
|---|---|---|
| コシヒカリ | 久井地区で最も多く作付けされると三原市資料に記載 | 未設定 |
| あきさかり | 三原市久井資料の主な作付品種 | 未設定 |
| あきろまん | 三原市久井資料の主な作付品種 | 未設定 |
| ヒノヒカリ | JA三原管内南部の主力品種として記録 | 未設定 |
| 恋の予感 | JA三原がヒノヒカリからの転換品種として本格導入 | 未設定 |

広島県農業技術センターも、2026年の主要な生育調査対象としてこの5品種を挙げている。

## 地域区分

広島県の栽培基準は標高で次のように区分している。

- 高冷地帯: 500m以上
- 北部地帯: 300m以上500m未満
- 中部地帯: 150m以上300m未満
- 南部地帯: 150m未満

久井町内でも標高差があるため、単一の「三原市ルール」だけで解決しない。圃場の代表点または標高を使い、まず広島県栽培地帯を決定してから品種ルールを解決する。

## 実装上の安全条件

- 品種マスターはルールがなくても選択できる。
- 有効なVarietyRuleがない作付けは`NOT_CONFIGURED`とし、刈取適期を推測表示しない。
- ルールには品種、地域、適用期間、版、出典、積算開始日、開始・中心・終了温度を必須保存する。
- 県資料にある「40日間880℃」は出穂晩限の検討値であり、品種別の刈取開始・終了温度として流用しない。
- 本番で`ACTIVE`にする前に、JAまたは県の栽培指導資料で品種別の刈取基準を確認する。
