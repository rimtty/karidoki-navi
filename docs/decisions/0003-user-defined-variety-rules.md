# ADR 0003: 公式閾値がない品種の扱い

- 状態: Accepted
- 決定日: 2026-09-03

## 決定

- 公的根拠を確認できない品種・地域の積算温度閾値は、公式マスターへ推測で登録しない。
- 利用者は、自身の作業ノートや営農指針で使用している「刈り始め・刈り終わり」の出穂後積算気温を、品種ごとに登録できる。
- 画面には農作業で使う上記2項目と「目安の出どころ」だけを表示する。内部処理に必要な中心値は開始・終了の中間から算出し、積算は出穂日当日から開始、地域は三原市久井町、適用開始日は保存日としてアプリが設定する。
- 利用者定義ルールには、登録者、根拠メモ、適用地域、適用期間、更新日時を保存する。
- 利用者定義ルールはアカウント内だけで有効とし、他の農家へ自動共有しない。
- 作付け登録時に適用ルールをスナップショット化し、後日のルール変更で過去の判定を変えない。
- 後から公式ルールが確認できた場合は、出典付きマスターとして追加し、利用者が次期作から選択できるようにする。

## 理由

広島県三原市久井町へ適用できる、初期5品種の出穂後積算日平均気温による刈取適期は、確認した公式一次資料からは得られなかった。別地域の値を転用すると、標高や栽培条件の差を隠したまま誤った刈取判断を示す恐れがある。一方、地域の営農指針や農家の運用値を明示的に登録できれば、根拠と責任範囲を保ちながら自動積算を利用できる。利用者に「offset」「適用期間」「中心値」などのシステム用語を入力させないことで、実際の作業ノートに近い操作にする。

## 承認

上記の推奨案について、プロジェクトオーナーの承認を2026-09-03に得た。
