# ADR 0002: MVPの気温データ取得元

- 状態: Accepted
- 決定日: 2026-09-03

## 決定

- MVPは、気象庁Webサイトが利用する地点別AMeDAS JSONを低頻度で取得する。
- 前日分の取得結果を保存し、同じ地点・日付への不要な再取得を避ける。
- 気象庁固有のURL、形式、品質コードは`WeatherProvider`の内側へ閉じ込める。
- 取得不能や仕様変更に備え、気象庁CSVの手動取込を代替経路として残す。
- 将来は同じProvider境界でWAGRI等へ差し替えられるようにする。
- 欠測値は0℃として扱わず、画面に欠測・更新遅れ・取得失敗を表示する。

## 理由

気象庁にはMVP要件を直接満たす、安定性が保証された公開APIを確認できていない。一方、地点別JSONから世羅（地点番号67316）の観測値を取得できることは確認した。無料データで自動積算する価値を検証しつつ、非保証エンドポイントへの依存を交換可能な境界へ限定する。

## 運用上の制約

- 高頻度・大量の取得を行わない。
- 取得元URL、取得日時、観測数、品質状態を記録する。
- 仕様変更を監視し、異常時は直近の保存値を表示してCSV取込へ切り替える。
- 非保証エンドポイントであることを運用資料に明記する。

## 承認

上記の推奨案について、プロジェクトオーナーの承認を2026-09-03に得た。
